# 动态规划之01背包问题（包含朴素版和优化版）

## 朴素版01背包
```c++
#include <bits/stdc++.h>
using namespace std;
const int N=1010;
int v[N],w[N],f[N][N];
int n,m;
int main()
{
    //01背包问题
    cin>>n>>m;
    for(int i=1;i<=n;i++)
    {
        cin>>v[i]>>w[i];
    }
    for(int i=1;i<=n;i++)
    {
        for(int j=0;j<=m;j++)
        {
            //不选i的情况
            f[i][j]=f[i-1][j];
            //选i的情况，曲线救国：先把i选了，在再剩下i-1和剩下体积m-v[i]里面去找
            //前提是j要大于等于v[i]
            if(j>=v[i]) f[i][j]=max(f[i][j],f[i-1][j-v[i]]+w[i]);
        }
    }
    cout<<f[n][m];
    return 0;
}
```
## 思考方式：
这一类背包问题的思考方式都差不多，先是考虑选还是不选，如果不选的话当前就等于上次的f[i-1][j]   
如果要选的话，我们不方便直接表示选这一操作，于是我们选择曲线救国，先把它选了，再把它带来的效果从中减去   
如体积和权重，我们一开始是默认不选的，后面在比较选的情况，这样每次比较都能得出最优解（注意你要选的话总体积j>=v[i])
*** 
## 优化版01背包
```c++
#include <bits/stdc++.h>
using namespace std;
const int N=1010;
int v[N],w[N],f[N];
int n,m;
int main()
{
    //01背包问题（优化版）
    //注意到每次的状态都只和上次有关，不妨去掉其中一个维度
    cin>>n>>m;
    for(int i=1;i<=n;i++)
    {
        cin>>v[i]>>w[i];
    }
    for(int i=1;i<=n;i++)
    {
        for(int j=m;j>=v[i];j--)
        {
            //选i的情况，曲线救国：先把i选了，在再剩下i-1和剩下体积m-v[i]里面去找
            //前提是j要大于等于v[i]
            if(j>=v[i]) f[j]=max(f[j],f[j-v[i]]+w[i]);
        }
    }
    cout<<f[m];
    return 0;
}
```
## 注意事项：
这里的这个优化版做了两个明显的变化：  
1. 从二维数组变化成了一维数组，为什么可以这样做呢，我们发现我们的状态方程只和我的上一次的状态有关，完全没有必要去循环i-2,i-3....
2. 还有一个变化就是在第二层循环里，变成倒序循环了，即从大往小遍历，为什么可以这样做呢：
   我们如果从小往大变化的话，小的要是先符合条件变化了，大的继续变化的话继承的是小的这个状态了，相当于一个物体取了两次，这就不是01背包问题了
   反而从大往小变的话，用到的都是上一次的旧状态，没什么影响，这就是这一题的巧妙之处，从二维变一维，巧妙地降低了内存，也实现了状态记录！
