# 计数dp之整数划分

## 法一（朴素做法
```c++
#include <bits/stdc++.h>
using namespace std;
const int N=1010,mod=1e9+7;
int f[N][N];
int n;
int main()
{
    cin>>n;
    f[0][0]=1;
    for(int i=1;i<=n;i++)
        for(int j=0;j<=n;j++)
        {
            f[i][j]=f[i-1][j];
            if(j>=i) f[i][j]=(f[i][j]+f[i][j-i])%mod;
        }
    cout<<f[n][n];    
    return 0;
}
```
### 思路：
这题做法和完全背包的思想非常类似，我们可以将此整数看作是一个大小为n的背包，用前1到n个数来填充该背包直至恰好填满  
那么根据完全背包做法，我们可以选这个数或者不选这个数  
当我们不选这个数时f[i][j]=f[i-1][j]  
当我们选这个数时 首先得判断背包和数的大小关系 f[i][j]+=f[i][j-i] 这里最后的状态时数量，所以我们这里用加号

## 法三（奇思妙想
```c++
#include <bits/stdc++.h>
using namespace std;
const int N=1010,mod=1e9+7;
int f[N][N];
int n;
int main()
{
    cin>>n;
    f[0][0]=1;
    for(int i=1;i<=n;i++)
    {
        for(int j=0;j<=i;j++)
        {
            f[i][j]=(f[i-1][j-1]+f[i-j][j])%mod;
        }
    }
    int res=0;
    for(int i=1;i<=n;i++) res=(res+f[n][i])%mod;
    cout<<res;
    return 0;
}
```
## 做法：
这里的f[i][j]的含义变了,i代表的是数的总和，j代表的是方案数  
这里我们分为两类，一类是方案数中的最小值为1，那么我们去除1，我们数的总和-1，我们的方案数也-1  
另一类是我们方案数中的最小值大于1，那么我们把所有数都-1，我们数的总和-j,但是此时方案数不变  
所以我们此时的转移方程为f[i][j]=f[i-1][j-1]+f[i-j][j]  
res只要把f[n][i]遍历一遍就行了，记住两次都要取模，不然爆int了！
