# 状态压缩DP之蒙德里安的梦想
## 代码如下：
```c++
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int N=12,M=1<<N;
ll f[N][M];
int n,m;
bool st[M];
int main()
{
    while(cin>>n>>m,n||m)
    {
        //先来初始化st
        for(int i=0;i<1<<n;i++)
        {
            st[i]=true;
            int cnt=0;
            for(int j=0;j<n;j++)
            {
                if(i>>j&1)
                {
                    if(cnt&1)
                    {
                        st[i]=false;
                        break;
                    }
                }
                else cnt++;
            }
            if(cnt&1) st[i]=false;
        }
        memset(f,0,sizeof f);
        f[0][0]=1;
        for(int i=1;i<=m;i++)
        {
            for(int j=0;j<1<<n;j++)
            {
                for(int k=0;k<1<<n;k++)
                {
                    if((j&k)==0 && st[j|k]) f[i][j]+=f[i-1][k];
                }
            }
        }
        cout<<f[m][0]<<"\n";
    }
}

```
## 思路和做法：
这道题比较秒，他要求的是在给出长为n，宽为m的矩形中找出能将该矩形恰好分成1x2个小矩形的方案数   
那我们的做法是先横着插满，再去判断竖着的是否合格（要求有**连续** **偶数个** 竖着的空格）这也是这题的难点  
我们是这样解决的 用for(j=0;j<n;j++) 来逐位拆开i,然后二进制话来判断是都与1相与为1，为1则意味着该地方被占了  
那么再去比较cnt和1相与的结果（这里有一个很巧妙的结论奇数与1与的结果为1，偶数与1与的结果为0）  
这样就初始化状态数组了   
还有一个点很容易忘的是记得初始化f[0][0]=1，有且仅有一种方案    
后面还有一个难点我们再统计f[i]列时，重点是看第i-1列的状态，看它有几个空位是否符合要求st[j|k]=true   
看它的i-2与i-1占位的状态是否矛盾了（j&k）==0   
如果这些都满足要求的话，那么f[i][j]+=f[i-1][k]  
最后的结果是f[m][0]  代表的是前m-1列已经填满了且没有超出来的元素
