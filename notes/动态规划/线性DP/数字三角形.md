# 线性DP之数字三角形（经典）

## 法一（从下至上）
```c++
#include <bits/stdc++.h>
using namespace std;
const int N=510;
int a[N][N],f[N][N];
int main()
{
    int n;
    cin>>n;
    for(int i=1;i<=n;i++)
        for(int j=1;j<=i;j++)
            cin>>a[i][j];
    for(int i=0;i<=n;i++)
        for(int j=0;j<=n;j++)
            f[i][j]=-1e9;
    for(int i=1;i<=n;i++) f[n][i]=a[n][i];
    for(int i=n-1;i>=1;i--)
        for(int j=1;j<=i;j++)
        f[i][j]=max(f[i+1][j],f[i+1][j+1])+a[i][j];
    cout<<f[1][1];    
    return 0;
}
```
## 思路：
这里的做法是先将f[n][i]最后一排的值赋值成a[n][i]最后一排的值，然后从下向上走，状态由前一步决定
f[i][j]=max(f[i+1][j],f[i+1][j+1])+a[i][j];

## 法二（从上至下）
```c++
#include <bits/stdc++.h>
using namespace std;
const int N=510;
int a[N][N],f[N][N];
int main()
{
    int n;
    cin>>n;
    for(int i=1;i<=n;i++)
        for(int j=1;j<=i;j++)
            cin>>a[i][j];
    for(int i=0;i<=n;i++)
        for(int j=0;j<=i+1;j++)
        f[i][j]=-1e9;
    f[1][1]=a[1][1];
    for(int i=2;i<=n;i++)
        for(int j=1;j<=i;j++)
        f[i][j]=max(f[i-1][j],f[i-1][j-1])+a[i][j];
    int res=-1e9;
    for(int i=1;i<=n;i++) res=max(res,f[n][i]);
    cout<<res;
    return 0;
}
```
## 差别：
这个做法看似和上面那种做法没什么区别，但是有两个小细节  
从下至上生成的是向下的两个叉，不存在边界问题，而从上至下生成的是向上的两个叉，这就需要考虑边界问题了   
在给f赋值时得稍微留意一下，或者都赋值为负无穷
