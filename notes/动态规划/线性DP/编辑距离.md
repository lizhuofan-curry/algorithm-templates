# 动态规划之编辑距离

## 最短编辑距离
```c++
#include <bits/stdc++.h>
using namespace std;
const int N=1010;
int n,m;
char a[N],b[N];
int f[N][N];
int main()
{
    cin>>n>>a+1;
    cin>>m>>b+1;
    //先来初始化
    //1.从a无字母变成b
    for(int i=0;i<=m;i++) f[0][i]=i;
    // 2.从a变为b空
    for(int i=0;i<=n;i++) f[i][0]=i;
    for(int i=1;i<=n;i++)
    {
        for(int j=1;j<=m;j++)
        {
            f[i][j]=min(f[i-1][j]+1,f[i][j-1]+1);
            if(a[i]!=b[j]) f[i][j]=min(f[i][j],f[i-1][j-1]+1);
            else f[i][j]=min(f[i][j],f[i-1][j-1]);
        }
    }
    cout<<f[n][m];
    return 0;
}
```
## 思路：
这题的思路比较巧妙，他同时比较了三种做法的最小值，一开始先默认了增删操作，后面再判断是否相等  
相等则比较f[i][j]和f[i-1][j-1]的关系，不相等就比较f[i][j]与f[i-1][j-1]+1之间的关系

## 编辑距离
```c++
#include <bits/stdc++.h>
using namespace std;
const int N=1010,M=15;
char str[N][M];
int n,m;
int minest(char a[],char b[])
{
    int la=strlen(a+1);
    int lb=strlen(b+1);
    int f[M][M]={0};
    for(int i=1;i<=lb;i++) f[0][i]=i;
    for(int i=1;i<=la;i++) f[i][0]=i;
    for(int i=1;i<=la;i++)
    {
        for(int j=1;j<=lb;j++)
        {
            f[i][j]=min(f[i-1][j]+1,f[i][j-1]+1);
            if(a[i]==b[j]) f[i][j]=min(f[i][j],f[i-1][j-1]);
            else f[i][j]=min(f[i][j],f[i-1][j-1]+1);
        }
    }
    return f[la][lb];
}
int main()
{
    cin>>n>>m;
    for(int i=1;i<=n;i++) cin>>str[i]+1;
    while(m--)
    {
        char s[15];
        int k;
        int res=0;
        cin>>s+1>>k;
        for(int i=1;i<=n;i++)
        {
            if(minest(str[i],s)<=k) res++;
        }
        cout<<res<<"\n";
    }
    return 0;
}
```
## 思路：
这题就是把上面那个做法变成函数做了一遍，但是有几个易错点
1. 注意我们从1开始输入，所以我们选择char a,char b来做
2. 我们s数组也选择char，这样方便一个个比较
3. 在算a,b长度时我们记得strlen(a+1)因为我们在主函数中的字符串是从一开始的
