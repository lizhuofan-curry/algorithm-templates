# 数据结构之哈希表
## 哈希表实现（拉链法）
```c++
#include <bits/stdc++.h>
using namespace std;
const int N=200003;
int h[N],e[N],ne[N],idx;
void insert(int x)
{
    //这样是为了处理负数
    int k=(x%N+N)%N;
     e[idx]=x;
    ne[idx]=h[k];
    h[k]=idx++;
}
bool find(int x)
{
    int k=(x%N+N)%N;
    for(int i=h[k];i!=-1;i=ne[i])
    {
        if(e[i]==x)  return true;
    }
    return false;
}
int main()
{
    //先用拉链法来解决哈希表
    int n;
    cin>>n;
    memset(h,-1,sizeof h);
    while(n--)
    {
        char op;
        int x;
        cin>>op>>x;
        if(op=='I')
        {
            insert(x);
        }
        else
        {
            if(find(x)) cout<<"Yes"<<"\n";
            else cout<<"No"<<"\n";
        }
    }
    return 0;
}

```
***  
### 注意点：  
- 这个哈希表在我的理解中和离散化最大的区别就是离散化要求有序，哈希表无序
- 实现哈希表也很容易，我们可以创建一个链表数组来解决冲突问题
- 先把头结点统一初始化为-1，这里用到的memset比较巧妙，值得学习
- 刚刚插入链表时忘记idx++了（哦补一句，这里用到的是头插，要是想用尾插也可以，就是有点麻烦）

## 哈希表实现（开放寻址法）
```c++
#include <bits/stdc++.h>
using namespace std;
const int N=200003,null=0x3f3f3f3f;
int h[N];
int find(int x)
{
    int k=(x%N+N)%N;
    while(h[k]!=null && h[k]!=x) {
        k++;
        if(k==N) k=0;
    }
    return k;
}
int main()
{
    int n;
    cin>>n;
    memset(h,0x3f,sizeof h);
    while(n--)
    {
        char op;
        int x;
        cin>>op>>x;
        if(op=='I')
        {
            h[find(x)]=x;
        }
        if(op=='Q')
        {
            if(h[find(x)]==x) cout<<"Yes"<<"\n";
            else cout<<"No"<<"\n";
        }
    }
    return 0;
}
```
*** 
### 注意点：
- 这个开放寻址法还是很有说法的，首先就是他这个N定义为输入次数的两到三倍而且是一个最小质数，后面都有数学支持的
- 然后就是定义null=0x3f3f3f3f 这个数恰好比1e9大一点点，支持将无限大做加减法
- find函数说白了就是在卫生间里找厕所，先去到你的区域内（k=(x%N+N)%N）
- 然后要这个坑位没人且等于你自己的名字，有一个不满足就换一个查看
- 这样插入和查找都能通过这个find实现了
- 哦还有一个注意点就是find函数循环完之后又得回数组头重新找（我刚刚就忘了）
