# 区间DP之石子合并问题
```c++
#include <bits/stdc++.h>
using namespace std;
const int N=310;
int f[N][N],sum[N];
int main()
{
    int n;
    cin>>n;
    for(int i=1;i<=n;i++)
    {
        cin>>sum[i];
        sum[i]=sum[i-1]+sum[i];
    }
    //先从小区间逐渐扩大到大区间来方便使用
    for(int len=2;len<=n;len++)
    {
        for(int i=1;i+len-1<=n;i++)
        {
            int l=i,r=i+len-1;
            f[l][r]=0x3f3f3f3f;
            for(int k=l;k<r;k++)
            {
                f[l][r]=min(f[l][r],f[l][k]+f[k+1][r]+sum[r]-sum[l-1]);
            }
        }
    }
    cout<<f[1][n];
    return 0;
}
```
## 到目前为止做了接近十道动态规划问题了，逐渐有了点经验，动态规划的核心思想是把大的状态分为多个小的状态，再依次细分，直到与已知挂钩  
嗯就拿这题来说吧，看似很难毫无头绪，但是你把问题细分，考虑到每个区间最后都是由两个区间合并起来的，这就是一个突破口了  
你再去想，既然每个区间都可以由两个区间合并起来，那这两个区间是不是有很多种情况呢，是不是有大有小呢   
这时候就会开始思考如何去解决多种情况的问题 ： 我们可以在确定区间长度的情况下去遍历  
那怎么确定区间长度，这时候顺便把小区间推出大区间问题一并解决了，可以让区间的长度有2开始，到n  
这就是这道题的思考过程了
