# 线性DP之最长上升子序列

## 朴素版DP
```c++
\#include <bits/stdc++.h>
using namespace std;
const int N=1010;
int a[N],f[N];
int main()
{
    int n;
    cin>>n;
    for(int i=1;i<=n;i++) cin>>a[i];
    for(int i=1;i<=n;i++)
    {
        f[i]=1;
        for(int j=1;j<i;j++)
        {
            if(a[i]>a[j])
            f[i]=max(f[i],f[j]+1);
        }
    }
    int res=0;
    for(int i=1;i<=n;i++)res=max(res,f[i]);
    cout<<res;
    return 0;
}
```
## 思路：
这个dp思路就是分为前n个f[i]状态，第一重循环为每个数，第二重循环为前i个数，通过与a[i]比较，来更新状态  
最后循环一遍f[i]求出最大值
