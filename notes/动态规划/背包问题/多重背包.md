# 动态规划之多重背包（三种解法）

## 法一 （多重背包朴素版）：
```c++
#include <bits/stdc++.h>
using namespace std;
const int N=1010;
int v[N],w[N];
int f[N][N];
int n,m;
int main()
{
    cin>>n>>m;
    for(int i=1;i<=n;i++) cin>>v[i]>>w[i];
    for(int i=1;i<=n;i++)
        for(int j=0;j<=m;j++)
            for(int k=0;k*v[i]<=j;k++)
            f[i][j]=max(f[i][j],f[i-1][j-k*v[i]]+k*w[i]);
    cout<<f[n][m];        
    return 0;
}
```
## 注意事项：
- 这种做法的时间复杂度达到了O(10^9),普通计算机1秒大约能跑10^7~10^8的基础运算，所以很明显超时了
- 这种做法和01背包的区别就是多了个可以无限取，在k=0的时候把f[i-1][j]包括进去了，所以不需要额外赋默认值了

## 法二（多重背包优化版）：
```c++
#include <bits/stdc++.h>
using namespace std;
const int N=1010;
int v[N],w[N];
int f[N][N];
int n,m;
int main()
{
    cin>>n>>m;
    for(int i=1;i<=n;i++) cin>>v[i]>>w[i];
    for(int i=1;i<=n;i++)
        for(int j=0;j<=m;j++)
            {
                f[i][j]=f[i-1][j];
                if(j>=v[i])
                f[i][j]=max(f[i][j],f[i][j-v[i]]+w[i]);
            }
    cout<<f[n][m];        
    return 0;
}
```
## 注意事项：
- 这里是根据推导得出来的结论：
  f[i][j]=max(f[i-1][j],f[i-1][j-v]+w,f[i-1][j-2v]+2w,f[i-1][j-3v]+3v)
  f[i][j-v]=max(        f[i-1][j-v],  f[i-1][j-2v]+w ,f[i-1][j-3v]+3v)
  所以我们从这里可以推出来f[i][j]=max(f[i-1][j],f[i][j-v]+w)
  我们从这里可以观察到,这里和01背包不一样，必须得正序循环，因为得用到当前状态下i的数据
- 其他的都和01背包差不多了，也要加上j>=v[i]的条件
***   
## 法三（结合01背包优化） 
```c++
#include <bits/stdc++.h>
using namespace std;
const int N=1010;
int v[N],w[N];
int f[N];
int n,m;
int main()
{
    cin>>n>>m;
    for(int i=1;i<=n;i++) cin>>v[i]>>w[i];
    for(int i=1;i<=n;i++)
        for(int j=v[i];j<=m;j++)
            {
                f[j]=max(f[j],f[j-v[i]]+w[i]);
            }
    cout<<f[m];        
    return 0;
}
```
## 注意事项：
结合法二那个形式我们很容易想到01背包的写法优化，所以我们也将多重背包的写法进行了优化，让时间复杂度更简洁
