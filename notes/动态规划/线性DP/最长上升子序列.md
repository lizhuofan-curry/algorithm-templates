# 线性DP之最长上升子序列

## 朴素版DP
```c++
\#include <bits/stdc++.h>
using namespace std;
const int N=1010;
int a[N],f[N];
int main()
{
    int n;
    cin>>n;
    for(int i=1;i<=n;i++) cin>>a[i];
    for(int i=1;i<=n;i++)
    {
        f[i]=1;
        for(int j=1;j<i;j++)
        {
            if(a[i]>a[j])
            f[i]=max(f[i],f[j]+1);
        }
    }
    int res=0;
    for(int i=1;i<=n;i++)res=max(res,f[i]);
    cout<<res;
    return 0;
}
```
## 思路：
这个dp思路就是分为前n个f[i]状态，第一重循环为每个数，第二重循环为前i个数，通过与a[i]比较，来更新状态  
最后循环一遍f[i]求出最大值
***

## 二分法加单调优化

```c++
#include <bits/stdc++.h>
using namespace std;
const int N=100010;
int a[N],f[N];
int n;
int main()
{
    cin>>n;
    for(int i=1;i<=n;i++) cin>>a[i];
    int len=0;
    f[0]=-1e9-10;
    for(int i=1;i<=n;i++)
    {
        int l=0,r=len;
        while(l<r)
        {
            int mid=(l+r+1)>>1;
            //找出小于a[i]最大的数
            if(f[mid]<a[i]) l=mid;
            else r=mid-1;
        }
        f[r+1]=a[i];
        len=max(len,r+1);
    }
    cout<<len;
    return 0;
}
```
## 思路：
这个做法较之前的朴素法时间复杂度大大降低了，之前的复杂度为O(n^2),二分优化后复杂度为O（nlogn）  
为什么可以这样做呢，我们定义f[n]为最长子序列中末尾最小的数，易证f是单调递增的  
所以我们通过二分查找出f中小于a[i]最大的那个数，将a[i]放其后面同时使f的长度增加   
最后循环完后f的长度就是我们要求的最长上升子序列长度
