# 数据结构之哈希表实现（拉链法）
```c++
#include <bits/stdc++.h>
using namespace std;
const int N=200003;
int h[N],e[N],ne[N],idx;
void insert(int x)
{
    //这样是为了处理负数
    int k=(x%N+N)%N;
     e[idx]=x;
    ne[idx]=h[k];
    h[k]=idx++;
}
bool find(int x)
{
    int k=(x%N+N)%N;
    for(int i=h[k];i!=-1;i=ne[i])
    {
        if(e[i]==x)  return true;
    }
    return false;
}
int main()
{
    //先用拉链法来解决哈希表
    int n;
    cin>>n;
    memset(h,-1,sizeof h);
    while(n--)
    {
        char op;
        int x;
        cin>>op>>x;
        if(op=='I')
        {
            insert(x);
        }
        else
        {
            if(find(x)) cout<<"Yes"<<"\n";
            else cout<<"No"<<"\n";
        }
    }
    return 0;
}

```
***  
## 注意点：  
- 这个哈希表在我的理解中和离散化最大的区别就是离散化要求有序，哈希表无序
- 实现哈希表也很容易，我们可以创建一个链表数组来解决冲突问题
- 先把头结点统一初始化为-1，这里用到的memset比较巧妙，值得学习
- 刚刚插入链表时忘记idx++了（哦补一句，这里用到的是头插，要是想用尾插也可以，就是有点麻烦）
