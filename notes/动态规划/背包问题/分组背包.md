# 动态规划之分组背包
## 法一（朴素版）
```c++
#include <bits/stdc++.h>
using namespace std;
const int N=110;
int v[N][N],w[N][N],s[N];
int f[N][N];
int n,m;
int main()
{
    cin>>n>>m;
    for(int i=1;i<=n;i++)
    {
        cin>>s[i];
        for(int j=0;j<s[i];j++)
        {
            cin>>v[i][j]>>w[i][j];
        }
    }
    for(int i=1;i<=n;i++)
        for(int j=0;j<=m;j++)
        {
            f[i][j]=f[i-1][j];
            for(int k=0;k<s[i];k++)
            if(j>=v[i][k])  f[i][j]=max(f[i][j],f[i-1][j-v[i][k]]+w[i][k]);
        }
    cout<<f[n][m];    
            
    return 0;
}
```
## 注意事项：
- 分组背包意思为有n个组，在每个组中只能选一个或者不选，是不是很像01背包
- 我自称它为二维01背包问题
- 所以在理解了这一点后，做法就很简单了，就按照01背包的做法做就行了

## 法二（仿01背包优化版）
```c++
#include <bits/stdc++.h>
using namespace std;
const int N=110;
int v[N][N],w[N][N],s[N];
int f[N];
int n,m;
int main()
{
    cin>>n>>m;
    for(int i=1;i<=n;i++)
    {
        cin>>s[i];
        for(int j=0;j<s[i];j++)
        {
            cin>>v[i][j]>>w[i][j];
        }
    }
    for(int i=1;i<=n;i++)
        for(int j=m;j>=0;j--)
            for(int k=0;k<s[i];k++)
              if(j>=v[i][k]) f[j]=max(f[j],f[j-v[i][k]]+w[i][k]);
        
    cout<<f[m];    
            
    return 0;
}
```
## 注意事项：
- 这里有两个坑点，首先这里优化后也和01背包一样得倒序循环，不然相当于放了多个进去
- 在优化后k循环不能写在j循环外面，如果说先循环决策的话，如果说一个组里面有两个物品，那么你在更新第一个物品的时候f的状态就是包括第一个物品的状态了。这样就做不到一组只选一个了
