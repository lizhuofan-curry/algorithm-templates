# 动态规划之多重背包

## 法一（多重背包朴素版）
```c++
#include <bits/stdc++.h>
using namespace std;
const int N=110;
int v[N],w[N],s[N];
int f[N][N];
int n,m;
int main()
{
    cin>>n>>m;
    for(int i=1;i<=n;i++) cin>>v[i]>>w[i]>>s[i];
    for(int i=1;i<=n;i++)
        for(int j=0;j<=m;j++)
            for(int k=0;k<=s[i] && k*v[i]<=j;k++)
                f[i][j]=max(f[i][j],f[i-1][j-k*v[i]]+k*w[i]);
    cout<<f[n][m];            
    return 0;
}
```
## 注意事项：
多重背包和完全背包相比就只多了一个s[i]每样物品个数的限制，所以朴素版我们只要在完全背包的基础上加一个k<=s[i]的条件判断    
那为什么我们不能像完全背包一样使用错位相减来做呢   
f[i][j]=max(f[i][j],f[i][j-v]+w,f[i][j-2v]+2w,....f[i][j-sv]+sw)     
f[i][j-v]=max(      f[i][j-v],  f[i][j-2v]+w,.....f[i][j-sv]+sw,f[i][j-(s+1)v]+(s+1)w)   
所以我们注意到后面多了一项，用不了错位相减！   
此时的时间复杂度为O(n*m*s)

## 法二（二进制优化多重背包）
```c++
#include <bits/stdc++.h>
using namespace std;
const int N=25000;
int v[N],w[N];
int f[N];
int n,m;
int main()
{
    cin>>n>>m;
    int cnt=0;
    while(n--)
    {
        int a,b,s;
        cin>>a>>b>>s;
        int k=1;
        while(k<=s)
        {
            cnt++;
            v[cnt]=a*k;
            w[cnt]=b*k;
            s-=k;
            k*=2;
        }
        if(s)
        {
            cnt++;
            v[cnt]=s*a;
            w[cnt]=s*b;
        }
    }
    n=cnt;
    for(int i=1;i<=n;i++)
        for(int j=m;j>=v[i];j--)
            f[j]=max(f[j],f[j-v[i]]+w[i]);
    cout<<f[m];        
    return 0;
}
```
## 注意事项：
- 很容易注意到上面的朴素做法时间复杂度为n*m*s,万一都在十的三次方就很容易超时了
- 我们于是选择用二进制将每个的s[i]拆开，相当于010101之间选择，将多重背包问题转化为01背包问题了
- 此时v[N]中的N为n*logs;所以时间复杂度为n*m*logs
